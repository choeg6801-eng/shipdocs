# 선적서류 작성기 Ledger

한 번 입력하면 영문 **P/I(견적송장) · C/I(상업송장) · P/L(포장명세서)** 3종을 함께 만드는 웹 페이지입니다.
로그인이나 서버 없이 브라우저에서 바로 동작합니다.

## 바로 쓰기

1. `index.html` 파일을 더블클릭해 크롬·엣지·사파리 등 브라우저로 엽니다.
2. **작성 시작하기**를 누릅니다. 처음에는 예시 데이터가 들어 있습니다.
3. 입력을 마치면 서류 탭에서 미리 보고 **PDF 저장**을 누릅니다.

인터넷이 없어도 동작합니다. 인터넷이 연결되어 있으면 글꼴(IBM Plex Sans KR)이 적용되고, 없으면 기기 기본 글꼴로 보입니다.

## 폴더 구성

| 파일 | 용도 |
|---|---|
| `index.html` | 파일 하나로 완성된 버전. 열어서 바로 쓰거나 그대로 웹에 올리면 됩니다. |
| `source/index.html` | 같은 사이트를 HTML·CSS·JS로 나눈 버전 (수정·GitHub 관리용) |
| `source/css/style.css` | 화면 디자인 |
| `source/js/app.js` | 입력·계산·점검·서류함·서류 생성 |
| `source/js/pdf.js` | PDF를 직접 만드는 코드 (외부 라이브러리 없음) |

## 웹에 올리기 (예: GitHub Pages)

1. GitHub에 새 저장소를 만들고 `index.html`을 올립니다. 나눈 버전을 쓰려면 `source` 폴더 안의 파일을 올립니다.
2. 저장소의 **Settings → Pages**에서 브랜치를 선택하면 주소가 생깁니다.

## 저장되는 위치

- 작성 중인 내용과 서류함은 **지금 쓰는 브라우저 안에만** 저장됩니다. 서버로 전송되지 않습니다.
- 다른 기기나 다른 브라우저로 옮기려면 **서류함 → 현재 건 백업 파일 저장**으로 `.json` 파일을 만들고, 옮긴 곳에서 **백업 파일 불러오기**를 쓰세요.
- 파일을 직접 열어 쓰는 경우 브라우저에 따라 파일 위치가 바뀌면 서류함이 비어 보일 수 있습니다. 중요한 거래는 백업 파일로 보관하세요.

## 주요 기능

- **한 번 입력:** 셀러·바이어, 수하인·착하 통지처, 인코텀즈, 결제 조건, L/C 상세, 운송, 품목·포장
- **서류 3종 자동 생성:** 영문 P/I·C/I·P/L 미리보기와 PDF 저장 (낱장·3종 묶음)
- **자동 계산:** 금액, 박스 수, 순중량·총중량(자투리 박스 실측 반영), CBM, 선금·잔금, 영문 금액 표기
- **불일치 점검:** 서류 간 수량·금액 차이, 인코텀즈·운송 방식, L/C 조건(부분선적·금액·최종 선적일), 보험 110% 등
- **대조표:** 품목별로 P/I · C/I · P/L 숫자를 나란히 비교
- **서류함:** 거래별 저장·열기·복사해 새 건(재주문), 내 회사 정보 저장
- **기타:** 엑셀 표 붙여넣기, 인코텀즈 2020 안내, 컨테이너 적재·항공 운임 중량 추정

## 주의

이 도구가 만든 서류는 **초안**입니다. 실제 선적 전에는 계약서, L/C 조건, 수입국 통관 요건과 대조해 최종 확인하세요.
컨테이너 적재량·항공 부피 중량 기준은 대략치이며, 실제 기준은 선사·항공사·포워더에 확인해야 합니다.
